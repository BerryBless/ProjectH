# Phase 14 Squad / DBNO / Revive / Reboot — 구현 기록 (Spec과 다른 점)

설계: `Docs/specs/2026-10-08-phase14-squad-dbno-design.md`(D1–D17). 동작 설명: `Docs/Squad.md`. 이 문서에는 구현하면서 Spec에 없던 것을 정했거나 Spec과 다르게 한 것만 적는다.

## 서버

| # | 내용 | 이유 |
|---|---|---|
| S1 | 소생은 대상 자리에 웅크린 상자(1.2 m)가 들어갈 공간이 있어야 시작된다. 완료 순간에도 다시 보고, 공간이 없으면 취소한다. | 기절 상자(0.9 m)만 들어가는 낮은 틈에서 일으키면 Shared 밀어내기가 몸을 위층 바닥 위로 올려 보낸다(실험으로 확인). Client 안내에는 이 검사가 없어서, 그런 드문 자리에서는 안내가 떠도 소생이 시작되지 않는다. |
| S2 | 출혈은 정수 체력에 나머지를 쌓아 줄인다(9 Tick마다 1, 900 Tick = 30초에 100). 소생 중에는 멈춘다. | 체력이 정수다. |
| S3 | 카드 수명은 월드에 놓여 있는 동안만 센다. 들고 있는 카드는 사라지지 않는다. | 주운 카드가 손에서 사라지면 플레이어가 이해하기 어렵다. |
| S4 | 연결이 끊긴(유예 중) 소생자의 소생은 바로 취소된다. | `InteractHeld`가 더 오지 않으므로 같은 결과이고, 놓친 입력 반복과 상관없이 정한다. |
| S5 | `HitConfirmed.Killed`는 탈락시킨 명중에서만 true다. 기절시킨 명중은 false다. | 처치 표시가 실제 탈락과 맞아야 한다. |
| S6 | 참가자 탈락의 `PlayerDied.Placement`는 항상 1 이상이다. 팀이 살아 있으면 그 순간 남은 팀 수(잠정), 팀이 전멸했으면 팀 배치다. 0은 늦은 관전자 안내 전용이다. | Client가 "처치자 0 + 배치 0 + 자기장"을 관전자 안내로 본다. 자기장 탈락이 안내로 오인되지 않게 한다. 최종 배치는 `MatchResult`만 정한다. |
| S7 | `TeamState`는 경기를 떠난 구성원을 목록에서 뺀다(Count가 준다). Solo도 1명짜리 팀으로 보낸다. | 떠난 사람을 HUD에 남기지 않는다. |
| S8 | 경기가 끝나면(Finished) 출혈·소생·재투입이 멈추고, 진행 중인 것은 `FinishMatch`가 끊는다(`ChannelState` active false를 팀에 보낸다). | 리뷰 Medium: 결과 화면 동안 우승팀 기절자가 출혈로 죽거나, 재투입이 배치 1을 0으로 바꾸던 문제. |
| S9 | 개발 모드 팀 번호는 지금 있는 플레이어 기준으로 자리가 남은 가장 작은 팀(없으면 쓰지 않는 가장 작은 번호)이다. | 리뷰 Low: 재접속이 255회 넘으면 번호가 한 바퀴 돌아 다른 사람과 같은 팀이 되던 문제. |
| S10 | `rebootLoadout`은 권총 대신 Wisp SMG(id 3) + Light 탄 30이다. | 무기 카탈로그에 권총이 없다. |
| S11 | `TeamState`는 최대 23 B다(헤더 3 B + 구성원 5 B × 4). | Spec의 26 B는 어림값이었다. |
| S12 | QA 명령 `downPlayer`, `giveRebootCard`, `setStationCooldown`, 액션 `holdInteract`, 사건 PlayerDowned·PlayerRevived·PlayerRebooted를 더했다. | 시나리오 준비와 확인용이다. Match에 QA 분기는 없다. |

## Client

| # | 내용 | 이유 |
|---|---|---|
| C1 | 팀원의 피격 Collider를 끈다. | D3(아군 사격 통과). 켜 두면 조준점이 팀원 몸에 찍혀 뒤의 적을 맞히지 못한다. |
| C2 | 늦은 관전자 안내는 "피해자 = 나 + 배치 0 + 처치자 0 + 자기장 + 내가 `TeamState` 팀에 없음"일 때만이다. 잠정 배치는 화면에 쓰지 않는다. | S6과 함께 오인을 막는다. |
| C3 | 소생 범위 2 m, 재투입 범위 3 m(높이 2 m), 출혈 30초, 기절 체력 100은 Client 표시용 복사 상수다(`SquadPrompt`). 서버 테스트가 `squad.json` 기본값과 같은지 비교한다(source link). | 안내 표시에 쓴다. 서버 값과 어긋나면 테스트가 잡는다. |
| C4 | 진행 막대는 `ChannelState`를 받은 순간의 추정 서버 Tick에서 시작해 끝 Tick에 끝난다. Resume으로 다시 받으면 0부터 다시 찬다. | 시작 Tick을 보내지 않는다(패킷 크기). |
| C5 | 분대 HUD는 팀이 2명 이상일 때만 보인다. | Solo 화면을 바꾸지 않는다. |
| C6 | 기절 팀원과 문이 함께 있는 곳에서 E를 누르면 Client의 문 예측이 한 번 틀릴 수 있다. 서버 `DoorStates`가 바로 고친다. | D7 우선순위는 서버만 안다. |

## 측정

`stress-quick` 5/5 PASS(50명). Mixed Match Tick p95 0.322 ms, Building p95 0.534 ms. 분대 Tick 코드는 할당이 없다(`SquadTicks_AllocateNothing`).

## Known Issues

- S1의 드문 자리에서는 소생 안내가 떠도 소생이 시작되지 않는다.
- 출혈 문구가 밝은 배경에서 잘 안 읽힌다(다듬기).
- 봇은 소생·재투입을 하지 않는다(D15, 다음 Phase 후보).
